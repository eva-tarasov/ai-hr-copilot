# Пятиминутная демонстрация AI HR Copilot (S06a)

Подготовка: установите зависимости и запустите FastAPI, Streamlit и `python -m scripts.demo_seed` по [README](../README.md). Используйте только временную SQLite и `LLM_PROVIDER=fake`. Seed создаёт 18 полностью синтетических документов и **не** запускает анализ. Манифест примеров: `python -m scripts.demo_fixtures`.

| Время | Действие | Что показать | Ценность для зрителя |
|---|---|---|---|
| 0:00–0:35 | Выбрать `AI HR Copilot — Synthetic Demo` в боковой панели. | Готовую вакансию и доступность локального сервера. | Сценарий воспроизводится без внешнего API или реальных персональных данных. |
| 0:35–1:05 | Открыть «Критерии». | Python и SQL как обязательные, Docker как желательный; все активны. | Человек задаёт профессиональные критерии до анализа. |
| 1:05–1:40 | Открыть «Резюме». | 18 записей: 15 `ready`, один PDF без текста `unsupported`, повреждённые PDF/DOCX `parse_error`. Повторный PDF не создал запись. | Ошибка одного файла не прерывает приём остальных, дубликат распознаётся по байтам. |
| 1:40–2:15 | Открыть «Анализ», нажать «Запустить анализ». | ID запуска, технические счётчики и прогресс. При быстром FakeProvider запуск может сразу завершиться: 15 завершены, 3 ошибки, `completed_with_errors`. При необходимости нажать «Обновить». | Видно состояние обработки; процент относится к документам, не к оценке людей. |
| 2:15–3:05 | Открыть «Результаты». | Матрицу с Python/SQL/Docker, легенду четырёх статусов и отдельный статус ошибок документов. | Сопоставление фактов без рейтингов, баллов и автоматического решения. |
| 3:05–4:10 | Выбрать `01-project-python.pdf`, затем `05-conflicting-python.pdf` или `02-skills-only.docx`; открыть `09-two-pages.pdf`. | Прямое подтверждение Python, противоречие либо только перечисление навыков; точные цитаты. У двухстраничного PDF Python — стр. 1, SQL и Docker — стр. 2. У DOCX номер страницы не указан. | Каждое утверждение можно проверить по источнику; противоречия поднимаются на ручную проверку. |
| 4:10–5:00 | Выбрать `03-no-docker.pdf`; показать `⚪ Не найдено в тексте`. | Сохранённый текст и отсутствие утверждения о Docker. | «Не найдено» означает лишь отсутствие сведений в документе, а не отсутствие навыка. HR уточняет факты и принимает решение самостоятельно. |

`FakeProvider` — детерминированная имитация для синтетических формулировок. Он не является полноценной оценкой реальной LLM; эта демонстрация не доказывает точность модели или ускорение работы HR. Сканированный PDF остаётся без OCR. Для повтора после изменения критерия можно создать второй запуск и сравнить сохранённые snapshots; не меняйте основной пятиминутный маршрут без необходимости.
